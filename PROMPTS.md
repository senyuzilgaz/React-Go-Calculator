# Prompts

Record of the prompts used to produce this project, grouped by session. Prompts are reproduced
**verbatim**, including typos, since the point of the record is what was actually asked.

Sessions are appended in the order they ran. Each session notes the agent used and what it
produced.

**On timestamps.** Times are local (UTC+03) and taken from the modification times of the
artifacts each turn produced. Where a turn produced no artifact that still carries its original
mtime, the time is given as a bounded range rather than a precise value, and marked as such.

### 2 — `internal/calc`

*2026-09-20, 17:39 – 17:41 (`errors.go`, `registry.go`, `format.go`)*

```text
Okay its going great thanks. now lets implement backend/internal/calc. This pacakage should be compeltely ignorent to http status codes json etc just the pure calculation logic. meaningful errors wrapped with context wherever possible and registry map is the only dispatch so adding new operations should results in just one new entry so no switch case if else etc.

```

**Outcome:** Three files at 100% statement coverage. No `switch`, `case`, or `else` anywhere in
the package, and each operation id appears exactly once in the source — inside its own registry
entry. Direct imports are `errors`, `fmt`, `math`, `strconv`, `strings`. Two test changes were
made and flagged: a helper renamed to avoid colliding with a new constant, and one assertion
that checked for `"1"` — which a NaN in the second operand satisfied accidentally via the echoed
operand — replaced with `"position 2"`, positions being 1-based to match the published messages.
An unreachable `ParseFloat` error branch was deleted rather than tested.

### 3 — `internal/transport/http`

*2026-09-20, 17:55 – 18:00 (transport package); ADR-0017 appended to `docs/DECISIONS.md`*

```text
now lets build the transport backend/internal/transport/http. Lets also implement tests using httptest agains the real router rather than calling handler functions directly as the routing and method matchings needs to be covered as well
```

**Outcome:** Router, handlers, DTOs, error mapping, and middleware at 100% coverage, with every
test driven through `httptest.NewServer(NewRouter(...))`. Two contract requirements turned out
not to be free: `ServeMux`'s automatic 405 is `text/plain` where the spec publishes a JSON
envelope, so each path is registered twice; and reporting an operand's position required
decoding operands one at a time, which also caught JSON `null` unmarshalling into a `float64`
without error and arriving silently as zero. The requested path diverged from ADR-0007's
`internal/httpapi`, so ADR-0017 was appended recording the move and the routing decisions it
forced, as an amendment rather than an edit to ADR-0007.

### 4 — Wiring: `cmd/server` and `internal/config`

*2026-09-20, 18:07 – 18:09 (config and server packages); ADR-0018 appended at 18:31*

```text

```

**Outcome:** `internal/config` at 100% coverage reading `PORT`, `LOG_LEVEL`, `ALLOWED_ORIGIN`,
and `SHUTDOWN_TIMEOUT`, validating strictly and reporting every problem at once; `cmd/server` at
92.2%, the remainder being `main()`'s `os.Exit` delegation and the `ErrServerClosed` shutdown
guard. The built binary was run and every example in `docs/API_EXAMPLES.md` reproduced
byte-for-byte, all seven error codes returned their documented status and message, and SIGTERM
shut the server down cleanly. Two corrections to the request: there is no registry for `main` to
build, since it is a package-level table in `calc` that `main` never imports; and the
request-id and structured-logging middleware already existed from turn 3. A test bug was found
and fixed — a bind-conflict test held `127.0.0.1:port` while the server binds every interface,
which `SO_REUSEADDR` allows to coexist.
